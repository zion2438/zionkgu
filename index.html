1. 원자료 탐색

현재 분석 자료: 없음

선택한 행이 각 열과 어떻게 연결되는지 확인합니다. 산업 행뿐 아니라 원표의 합계·분석지표 행도 포함됩니다.

기본 자료를 불러온 후 표시됩니다.
열 코드열 이름원자료 값

스크롤하여 전체 열을 볼 수 있습니다. 금액표의 일반 데이터 단위는 백만원입니다. 구성비·유발계수 등 요약 행은 행 명칭을 우선 확인하세요.

2. 국내 생산물 최종수요 증가 시뮬레이션

수입 완제품 구매를 제외한 국내 생산물 최종수요 증가를 입력하세요. 여러 산업의 증가액은 합산됩니다.

1,000백만원 = 10억원. 이번 버전은 양의 수요 증가만 지원합니다.

    시나리오를 추가하세요.

    생산유발액 상위 15개 산업

    산업별 유발액 — 백만원, 생산유발액 내림차순
    코드산업생산수입부가가치

    3. 산업별 생산유발계수 순위

    어느 산업의 최종수요가 늘어날 때, 경제 전체의 생산이 더 많이 늘어나는가?

    선택한 분류에서 각 산업의 국내 생산물 최종수요가 각각 100억 원 증가할 때의 전체 생산 증가액을 비교합니다.

    먼저 산업 분류 자료를 불러오세요.

    검색어가 없으면 상위 10개만 표시합니다.
    전체 순위코드산업생산유발계수 (배)전체 생산 증가액 (억 원)

    4. 두 시나리오 비교

    같은 100억 원을 다르게 배분하면 결과가 어떻게 달라질까?

    시뮬레이터에서 계산한 결과를 A안으로 저장한 다음, 입력을 바꿔 다시 계산하면 새 결과가 B안으로 표시됩니다. 100억 원은 10,000백만원입니다.

    먼저 시뮬레이션 결과를 A안으로 저장하세요.

    단위: 백만원 · 차이 = B안 − A안
