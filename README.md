# 2023년 산업연관표 분석 웹앱

2023년 산업연관표를 바탕으로, 특정 산업의 최종수요가 늘어날 때 생산·부가가치·수입이 얼마나 늘어나는지 살펴보는 산업조직론 과제 웹앱입니다.

[웹앱 바로가기](https://zion2438.github.io/zionkgu/)

## 주요 기능과 사용법

### 1. 산업 분류 선택 및 원자료 탐색

**기본부문(380개), 통합대분류(33개), 통합중분류(83개), 통합소분류(165개)** 중 하나를 선택하고 **선택한 분류 불러오기**를 누릅니다. 시트를 바꾸거나 행·열을 이름과 코드로 검색해 원자료를 확인할 수 있습니다. 거래액과 계수는 단위가 다르므로 화면의 단위 안내와 원표의 행·열 명칭을 확인합니다.

### 2. 최종수요 증가 시뮬레이션

산업을 선택하고 국내 생산물의 최종수요 증가액을 **백만원** 단위로 입력합니다. **시나리오에 추가 → 파급효과 계산**을 누르면 생산유발액·부가가치유발액·수입유발액을 확인할 수 있습니다. 한 시나리오에 여러 산업을 추가할 수 있으며, 산업별 결과는 CSV로 내려받을 수 있습니다.

### 3. 산업별 생산유발계수 순위


각 산업의 국내 생산물 최종수요가 **각각 100억 원씩 따로** 증가한다고 가정해 전체 생산 증가액을 비교합니다. **순위 계산**을 누르면 상위 10개 산업이 표시되며, 산업명이나 코드를 검색하면 해당 산업의 전체 순위를 확인할 수 있습니다. 생산유발계수가 1.8배라면 최종수요 100억 원 증가에 따른 전체 생산 증가액이 180억 원이라는 뜻입니다. 이 수치는 이익이나 GDP 증가액이 아닙니다.

### 4. 두 시나리오 비교


1. 같은 분류 안에서 첫 시나리오의 **파급효과 계산**을 누른 뒤 **A안으로 저장**을 누릅니다.
2. **시나리오 비우기**를 누르고 두 번째 시나리오를 입력한 뒤 다시 계산합니다. 새 결과가 자동으로 B안에 표시됩니다.
3. **두 시나리오 비교**에서 생산·부가가치·수입 유발액과 **차이(B안 − A안)**를 백만원 단위로 확인합니다.

예를 들어 A안은 한 산업에 **10,000백만원(100억 원)**, B안은 두 산업에 각각 **5,000백만원(50억 원)**을 배분할 수 있습니다. 총액이 같으므로 수요의 배분 방식에 따른 차이를 비교할 수 있습니다. 다른 분류의 자료를 불러오면 저장된 A안은 초기화됩니다.

## 분석 방법

선택한 분류의 생산·부가가치·수입 유발계수표에 산업별 최종수요 증가액 벡터를 각각 곱해 산업별 파급효과를 계산합니다. 생산유발계수 순위는 생산유발계수표의 **산업별 열 합계**를 내림차순으로 정렬한 것입니다. 열 합계는 해당 산업의 최종수요 1단위 증가가 모든 산업의 생산을 합쳐 얼마나 늘리는지 나타냅니다.
