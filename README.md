# 2023년 산업연관표 분석 웹앱

## 사용법
1. 기본부문·통합대분류·통합중분류·통합소분류 중 하나를 선택하고 **선택한 분류 불러오기**를 누릅니다.
2. 원자료 탐색에서 시트와 행을 선택하거나 이름·코드로 검색합니다.
3. 시뮬레이터에서 국내 생산물 최종수요 증가액(백만원)을 추가하고 **파급효과 계산**을 누릅니다. 여러 산업을 입력하면 수요 증가분을 합산합니다. 다른 분류를 불러오면 이전 시나리오는 초기화됩니다.
4. **순위 계산**으로 상위 10개 부문을 확인하거나 이름·코드로 전체 순위를 검색합니다.

## 분석 방법
선택한 분류의 공식 생산·수입·부가가치 유발계수 행렬에 최종수요 증가 벡터를 곱합니다. 생산유발계수 순위는 생산유발계수 행렬의 산업별 열 합을 내림차순으로 정렬합니다. 이 값(배)에 100을 곱하면 각 산업의 국내 생산물 최종수요가 독립적으로 100억 원 늘었을 때 경제 전체 생산 증가액(억 원)이 됩니다. 총산출 증가액이며 GDP 증가액은 아닙니다.
